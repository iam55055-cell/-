# 뉴과 앵커 영상 아바타 촬영 대본

영상 아바타(AI Studios 인스턴트 커스텀 아바타, 또는 HeyGen 디지털 트윈)를 만들기 위한 촬영용 대본이다.
전체 약 **3분**. 프롬프터용 글자만 모은 파일: `docs/avatar-video-shoot-prompter.txt`

---

## 촬영 전 체크리스트

**장비·구도**
- [ ] 휴대폰 **가로**, 삼각대 고정, **1080p 이상** (4K면 더 좋음), 30fps
- [ ] 카메라 **눈높이**, 1.5~2m 거리, **가슴 위까지** 보이게 (머리 위 여백 손가락 두 마디)
- [ ] 줌 쓰지 않기, 촬영 중 카메라 건드리지 않기
- [ ] 휴대폰 **방해 금지 모드**, 저장 공간 확인

**조명·배경**
- [ ] 창문을 **마주 보고** 서거나, 조명 2개를 얼굴 양옆 45도에
- [ ] 뒤에서 들어오는 빛 없음, 얼굴에 그림자 없음
- [ ] 배경: **단색 벽**(회색·흰색) 또는 **초록 천** (주름 펴기)
- [ ] 주변 소음 없음 (에어컨, TV, 창문)

**옷·외모**
- [ ] 정장 + **민무늬 넥타이** (가는 줄무늬는 화면에서 물결무늬가 생김)
- [ ] 초록 천 배경이면 초록색 옷 금지
- [ ] 안경에 조명이 비치지 않는지 확인 (비치면 조명 각도를 바꾼다)
- [ ] 머리 정리, 셔츠 깃 정리. 껌·사탕 금지

**말하는 법**
- [ ] 렌즈를 본다 (화면 속 내 얼굴 말고 렌즈)
- [ ] 평소 말투, 속도는 조금 천천히
- [ ] `[쉼]` 표시에서 **입을 다물고 가만히** (AI가 말하지 않을 때 모습을 배운다)
- [ ] 고개는 살짝 끄덕이는 정도, 손은 프레임 밖에 두거나 아주 작게
- [ ] 손이 얼굴·입을 가리지 않는다
- [ ] 틀려도 멈추지 말고 그 문장만 다시 읽고 이어 간다
