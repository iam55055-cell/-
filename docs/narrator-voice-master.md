# 어제뉴스 나레이터 마스터 레퍼런스 (v0.1)

> 모든 회차의 나레이션은 이 문서와 **마스터 보이스**를 기준으로 만든다.
> 목소리가 회차마다 조금씩 달라지면 채널이 하나의 인격으로 느껴지지 않는다.

---

## 1. 목소리 인물상

| 항목 | 기준 |
|---|---|
| 한 줄 정의 | **뉴스를 다 읽고 와서, 그 뒤 이야기를 들려주는 동네 형** |
| 성별·나이감 | 남성, 30대 후반~40대 초반 |
| 음역 | 중저음. 앵커보다 반 톤 낮게 |
| 질감 | 맑고 또렷하다. 허스키하거나 숨이 많이 섞이면 안 된다 |
| 거리감 | 앵커보다 가깝고, 친구보다 멀다. 존댓말이 기본 |
| 감정 폭 | 좁게. 흥분하지 않는다. 놀라운 대목일수록 **낮고 느려진다** |

### 이런 목소리가 아니다

- 뉴스 앵커: 너무 딱딱하고 정보만 전달한다
- 유튜브 텐션: 들뜨고 빠르고 소리 지른다
- 다큐 성우: 무겁고 장엄해서 15분 듣기 지친다
- 수면 유도 낭독: 너무 느리고 평평하다

벤치마크인 지식해적단과 비교하면, 말의 리듬은 비슷하게 가져가되 감정 폭은 절반 정도로 줄인다.

---

## 2. 말투 모드 6가지

대본의 구간마다 아래 모드 중 하나를 쓴다. 대본에 모드 이름을 적어 두면 녹음과 TTS 설정이 쉬워진다.

| 모드 | 쓰는 곳 | 속도 | 높낮이 | 전달 방법 |
|---|---|---|---|---|
| **훅** | 영상 첫 30초 | 보통보다 약간 느리게 | 중간 | 짧게 끊는다. 문장 사이 쉼을 길게 |
| **설명** | 과거 서사, 배경 | 보통 | 중간, 평평 | 담담하게. 연도와 숫자만 살짝 힘을 준다 |
| **메인 킥** | 영상당 한 번 | 가장 느리게 | **가장 낮게** | 한 줄씩 쌓고 쉰다. 마지막 문장은 속삭이듯 낮춘다 |
| **펀치라인** | 1분에 하나 이하 | 약간 빠르게 | 살짝 올림 | 가볍게 툭 던진다. 웃음을 기다리지 않는다 |
| **나란히 놓기** | 서로 다른 주장 비교 | 보통 | 중간 | 감정을 완전히 뺀다. 인용은 인용답게 평평하게 |
| **루프** | 영상 마지막 | 느리게 | 질문 끝만 올림 | “그런데요.” 다음에 1초 쉬고 질문 |

### 전쟁·재난·사망 대목

펀치라인을 쓰지 않는다. 설명 모드에서 속도를 조금 더 늦춘다.

## 3. 속도와 쉼

| 항목 | 기준 |
|---|---|
| 기본 속도 | 분당 약 330자 (공백 제외) |
| 쉼표(,) | 0.3초 |
| 마침표(.) | 0.6초 |
| 대본의 `(쉼)` | 1초 |
| 구간 전환 | 1.5초. 편집에서 효과음이나 화면 전환으로 채운다 |
| 메인 킥 줄 사이 | 1초 이상 |

TTS에서는 쉼표, 줄바꿈, 말줄임표(...)로 쉼을 만든다. 한 문장이 25자를 넘으면 쉼표로 나눈다.

## 5. 기준 대본 (마스터 레퍼런스용, 약 1분)

후보 목소리를 고르고, 마스터 보이스를 복제 등록할 때 이 대본을 쓴다. 여섯 가지 모드와 발음 사전의 까다로운 단어가 모두 들어 있다.

```
[훅]
10월 29일. 단 20분.
세계 최대 코인 거래소에서, 8조 4천억 원이 빠져나갔습니다.
총 한 자루, 복면 하나 없이.
FBI가 지목한 범인은, 북한 해킹 조직 트레이더트레이터.

[설명]
1976년 가을, 덴마크와 노르웨이, 스웨덴, 핀란드는 거의 동시에 북한 외교관들을 쫓아냅니다.
이유는, 밀수였습니다.

[메인 킥]
그런데 탈북자들의 증언에 따르면, 해킹에 성공한 해커에게는 평양 아파트가 나옵니다.
지방에 살던 부모까지... 함께 올라와 살 수 있습니다.
한 번의 해킹이, 한 사람이 아니라 한 집안의 신분을 바꾸는 겁니다.

[펀치라인]
오타 하나가 2천만 달러를 지킨 겁니다. 영어 공부가 이렇게 중요합니다.

[나란히 놓기]
FBI는 북한 소행이라고 했습니다. 김여정은, 황당무계한 낭설이라고 했습니다.

[루프]
그런데요. 8조 원어치 코인, 북한은 정말 쓸 수 있을까요?
어제뉴스였습니다.
```

## 7. 마스터 보이스 확정 절차

1. 후보 중 하나를 고른다
2. 고른 목소리로 기준 대본을 다시 생성한다. 필요하면 속도와 쉼을 조정한다
3. 그 음성 파일을 Higgsfield에 **“어제뉴스 마스터 보이스”** 로 복제 등록한다 (30초 버전, 전체 버전 두 개)
4. 등록된 voice_id를 아래에 적는다. 이후 모든 회차는 이 ID로만 생성한다

| 항목 | 값 |
|---|---|
| 마스터 보이스 이름 | 미정 |
| 원본 목소리 | 미정 |
| Higgsfield voice_id | 미정 |
| 생성 설정 | 미정 |
| 확정일 | 미정 |

### 직접 녹음으로 갈 경우

본인 목소리로 간다면 이 기준 대본을 조용한 방에서 휴대폰으로 녹음하면 된다. 그 파일을 같은 방식으로 복제 등록할 수 있다. 1장의 인물상과 2장의 모드 표는 그대로 녹음 지침으로 쓴다.
