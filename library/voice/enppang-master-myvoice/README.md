# 엔빵 마스터 보이스: 본인 목소리 (2026-11-22)

엔빵의 나레이션 기준은 진행자 본인 목소리다. 이 폴더에는 그 기준이 되는 녹음(마스터 레퍼런스)의 대본과 설정을 둔다.
말투와 읽는 법은 `docs/enppang-narrator-master.md`에 있다.

## 개인정보 보호

이 저장소는 **공개(public)** 상태다. 본인 목소리 음성 파일(`*.mp3`, `*.wav`, `*.m4a`)은
이 폴더의 `.gitignore`로 막아서 GitHub에 올리지 않는다. 대본과 설정만 올린다.
음성 파일 원본은 진행자 컴퓨터와 구글 드라이브에 보관한다.

## 들어 있는 파일

| 파일 | 내용 | GitHub |
|---|---|---|
| `my-voice-reference.txt` | 녹음 대본. 엔빵 기준 대본 (공백 제외 361자, 17줄, 약 1분) | 올림 |
| `preset.json` | 설정. 아직 정해지지 않은 값은 "미정"으로 적었다 | 올림 |
| `my-voice-original.*` | 받은 녹음 그대로 | 올리지 않음 |
| `my-voice-reference.wav`, `.mp3` | 정리본: 70Hz 이하 제거, 약한 잡음 제거, -16 LUFS | 올리지 않음 |

## 뉴과 녹음과 다른 점

뉴과용 본인 목소리 녹음(`library/voice/nyugwa-master-myvoice/`, 1분 5초)이 이미 있다. 목소리는 같지만 그 대본에는
엔빵에서 쓰는 유행어와 감탄사, 숫자를 연달아 읽는 문장이 없다. 엔빵은 이 폴더의 대본으로 따로 녹음한다.

## 순서

1. `my-voice-reference.txt`를 본인 목소리로 녹음한다. 방법은 `docs/enppang-narrator-master.md` 4장
2. 녹음 파일을 작업방에 올린다
3. 정리본을 만들고 분당 글자 수를 잰다. 잰 값을 `preset.json`과 `docs/enppang-narrator-master.md` 5장에 적는다
4. 회차를 만든다. 직접 녹음하는 회차는 녹음 전에 정리본을 듣고 톤과 속도를 맞춘다. 목소리 클론으로 만드는 회차는 정리본으로 클론을 등록한다
