# 뉴과 마스터 보이스: 본인 목소리 (등록 2026-11-17)

화면에 진행자 본인 얼굴(AI Studios 포토 아바타)이 나오므로, 나레이션도 본인 목소리로 바꾼다.
타입캐스트 · 민욱(`library/voice/nyugwa-master/`)은 예비 목소리로 남겨 둔다.

## 개인정보 보호

이 저장소는 **공개(public)** 상태다. 본인 목소리 음성 파일(`*.mp3`, `*.wav`, `*.m4a`)은
이 폴더의 `.gitignore`로 막아서 GitHub에 올리지 않는다. 설정과 대본만 올린다.
음성 파일 원본은 진행자 컴퓨터와 구글 드라이브에 보관한다.

## 들어 있는 파일

| 파일 | 내용 | GitHub |
|---|---|---|
| `my-voice-original.mp3` | 받은 녹음 그대로 (1분 5초) | 올리지 않음 |
| `my-voice-reference.wav` | 보이스 클론용 정리본: 70Hz 이하 제거, 약한 잡음 제거, -16 LUFS | 올리지 않음 |
| `my-voice-reference.mp3` | 위와 같은 내용의 MP3 | 올리지 않음 |
| `my-voice-reference.txt` | 녹음 대본 (1분 레퍼런스 대본) | 올림 |
| `preset.json` | 제작 설정 | 올림 |

## 적용 순서 (AI Studios)

1. 왼쪽 메뉴 **음성** → 내 목소리 만들기 → `my-voice-reference.wav` 업로드 → 이름 `뉴과 본인 목소리`
   - 녹음 대본을 요구하면 `my-voice-reference.txt` 내용을 붙여넣는다
   - 더 긴 녹음을 요구하면 같은 대본을 두세 번 읽어 2~3분으로 다시 녹음한다
2. 영상 프로젝트: 아바타는 뉴스 스튜디오 포토 아바타, 대본 칸(👤 탭)에 원고를 붙여넣고 목소리를 `뉴과 본인 목소리`로 고른다
3. 속도 0.9 기준으로 맞추고 들어 본다
4. 내보내기: 모션 엔진 **dvtalker (0 크레딧)**, 1080p
5. 배경음악은 내보낸 뒤 편집에서 깐다 (립싱크용 음성에는 음악을 넣지 않는다)
