# 엔빵 로고와 채널 심볼 (시안 v0.2, 2026-11-22)

> 상태: **시안**. 채널 심볼은 A를 추천안으로 두고 B·C를 함께 만들었다. 같은 날 "N + 0" 변형 다섯 가지를 더 그렸다. 사용자가 고르면 확정한다.
> 시안을 한눈에 보는 화면: https://claude.ai/artifact/CNBHmkV52AYoSEuMdtXtwq (비공개. 만든 사람만 열 수 있다)
> 한 장짜리 미리보기: `png/preview.png` (워드마크와 심볼 A·B·C), `png/preview-n0.png` (N + 0 변형)

## 생각

- **'엔'의 ㅇ 자리에 N으로 쪼개진 동전을 넣었다.** 내 돈 한 닢을 여럿이 나눠 갖는다는 뜻이고, 엔빵의 엔(N)이기도 하다
- **그 동전을 떼어 낸 것이 채널 심볼이다.** 워드마크와 심볼이 한 벌이 된다
- 글자는 글꼴을 쓰지 않고 도형으로 직접 그렸다. AI 이미지도 쓰지 않았다
- 한 줄 설명 "내 돈 나눠 먹는 사람들"을 붙인 로고를 따로 두었다. 기획서는 이름만 보면 더치페이 채널로 오해할 수 있으니 한 줄 설명을 붙여 쓰라고 적었다

## 세 심볼의 차이

| 시안 | 좋은 점 | 약한 점 |
|---|---|---|
| A. N으로 쪼개진 동전 | 워드마크 속 동전과 같은 모양. 24px에서도 N이 읽힌다 | 채널 이름이 글자로 보이지는 않는다 |
| B. 영수증 위의 N | 매 편 마지막의 영수증 한 장, 제목 기호 🧾와 이어진다 | 워드마크의 동전과 다른 그림이라 한 벌이 아니다. 24px에서는 영수증 모양이 뭉개진다 |
| C. 글자 그대로 | 이름이 바로 읽힌다 | 32px 아래에서는 글자가 뭉개진다 |

## N + 0 변형 다섯 가지 (2026-11-22 추가)

사용자가 고리 안에 N이 든 로고 사진을 참고로 보내고, "N + 0"의 뜻으로 다섯 가지를 그려 보라고 했다. 엔빵을 엔(N) + 빵(0)으로 읽는다는 뜻으로 받아들였다.

- 참고 사진은 다른 사람이 만든 로고다. 따라 그리지 않았고 저장소에도 넣지 않았다
- 다섯 가지 모두 도형으로 새로 그렸다. 글꼴과 AI 이미지는 쓰지 않았다

| 번호 | 이름 | 그림 | 좋은 점 | 약한 점 |
|---|---|---|---|---|
| 1 | 빗금 친 0 | 0의 양옆이 N의 기둥이 되고, 빗금이 N의 대각선이 된다 | 한 덩어리라서 작아져도 모양이 남는다 | 둥근 네모라서 ㅁ이나 금지 표시로 읽힐 수 있다. N인 줄 한 번에 알아보기 어렵다 |
| 2 | 0 속의 N | 세로로 긴 0 안에 N이 떠 있다 | N과 0이 글자 그대로 보인다. 20px에서도 둘 다 보인다 | 고리 안의 글자는 가장 흔한 구도이고, 참고 사진과도 구도가 같다. 워드마크에 넣으면 고리가 가늘어 밝은 바탕에서 옅다 |
| 3 | N 어깨 위의 0 | 굵은 N의 오른쪽 어깨에 작은 0이 붙어 있다 | N이 가장 크다. 20px에서 N이 가장 잘 읽힌다 | "N의 0제곱"이나 온도 표시(°)로 읽힌다. 0이 20px에서는 점이 된다 |
| 4 | 0을 뚫고 나온 N | N이 동전을 뚫고 지나가고, 겹친 곳은 색이 뒤집힌다 | 큰 화면에서 가장 눈에 띈다 | 24px에서는 무늬가 뭉개지고 36px부터 읽힌다. 프로필 사진으로는 맞지 않는다 |
| 5 | N이 쪼갠 0 | N이 가른 동전의 두 반쪽이 엇갈려 미끄러진다 | "나눠 먹는다"는 뜻이 그림에 있다. 심볼 A와 같은 식구다 | 0이 깨져 있어서 0으로는 덜 읽힌다. N이 빗금처럼 보일 수 있다 |

- **고르지 않았다.** 프로필 사진으로는 2번(N과 0이 둘 다 또렷하다)과 5번(채널의 뜻이 담긴다)이 후보다
- 워드마크의 ㅇ 자리에는 둥근 모양인 2번과 5번만 들어간다. 1번은 ㅁ으로 읽히고, 3번과 4번은 ㅇ 모양이 아니다
- 작은 크기는 20·24·36·48px로 그려서 확인했다
- 5번을 밝은 바탕에 쓸 때는 N 자리를 잉크색으로 채운다. 금색 조각만으로는 밝은 바탕에서 N이 보이지 않는다

## 쓰는 법

- 밝은 바탕에는 `wordmark.svg`, 어두운 바탕에는 `wordmark-on-dark.svg`, 금색 바탕에는 `wordmark-on-gold.svg`를 쓴다. 금색 바탕에 기본 워드마크를 올리면 동전이 묻힌다
- 처음 보는 사람에게 닿는 자리(채널 배너, 영상 첫 화면)에는 한 줄 설명을 붙인 로고를 쓴다
- 글자의 비율과 동전 안의 N은 바꾸지 않는다. 늘이거나 기울이지 않는다

## 유튜브 프로필 사진 올리기

1. 유튜브 스튜디오 → 맞춤설정 → 프로필 → 사진에서 `png/channel-icon-800.png`를 올린다
2. 유튜브는 프로필 사진을 원형으로 잘라 보여 준다. 심볼은 원 안에 다 들어가게 그려 두었다

여러 안내 글에 따르면 권장 크기는 800×800px, 용량은 4MB 이하이고 JPG·GIF·BMP·PNG를 받는다(움직이는 GIF 제외). 2MB라고 적은 글도 있다. 이 파일은 약 37KB다. 유튜브 공식 안내는 직접 확인하지 못했으니 올리는 화면의 안내를 따른다.

## 다시 만들기

```
python3 scripts/enppang_logo.py library/brand/enppang/svg <NotoSansKR-Bold.ttf 경로>
python3 scripts/enppang_logo_n0.py library/brand/enppang/svg/n0
node scripts/enppang_logo_png.js library/brand/enppang
```

- 글자와 심볼의 모양, 색, 비율은 `scripts/enppang_logo.py`의 숫자로 정해져 있다
- N + 0 변형은 `scripts/enppang_logo_n0.py`가 그린다. 워드마크에 넣어 보는 그림은 `enppang_logo.py`의 글자 모양을 불러다 쓴다
- 한 줄 설명의 글꼴은 Noto Sans KR Bold다 (SIL Open Font License). 글꼴 파일은 저장소에 넣지 않았다. 윤곽선으로 바꿔 넣었으므로 SVG를 여는 데는 글꼴이 필요 없다
- PNG 내보내기에는 Playwright(Chromium)가 필요하다

## 확인하지 못한 것

- **비슷한 로고가 이미 있는지 찾아보지 않았다.** 원 안의 N은 흔한 모양이다. 변형 2번은 그 구도 그대로라서, 고르기 전에 비슷한 로고와 상표부터 찾아봐야 한다
- **상표.** 기획서에 따르면 "N빵"은 36류·38류에 케이뱅크 등록이 있고, 41류 등록 여부와 변리사 확인이 남아 있다. 심볼에 알파벳 N을 썼으니 그때 로고도 함께 보여 준다
- 채널 배너와 영상 워터마크는 아직 만들지 않았다
