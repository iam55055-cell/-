# 엔빵 로고와 채널 심볼 (시안 v0.1, 2026-11-22)

> 상태: **시안**. 채널 심볼은 A를 추천안으로 두고 B·C를 함께 만들었다. 사용자가 고르면 확정한다.
> 시안을 한눈에 보는 화면: https://claude.ai/artifact/CNBHmkV52AYoSEuMdtXtwq (비공개. 만든 사람만 열 수 있다)
> 한 장짜리 미리보기: `png/preview.png`

## 생각

- **'엔'의 ㅇ 자리에 N으로 쪼개진 동전을 넣었다.** 내 돈 한 닢을 여럿이 나눠 갖는다는 뜻이고, 엔빵의 엔(N)이기도 하다
- **그 동전을 떼어 낸 것이 채널 심볼이다.** 워드마크와 심볼이 한 벌이 된다
- 글자는 글꼴을 쓰지 않고 도형으로 직접 그렸다. AI 이미지도 쓰지 않았다
- 한 줄 설명 "내 돈 나눠 먹는 사람들"을 붙인 로고를 따로 두었다. 기획서는 이름만 보면 더치페이 채널로 오해할 수 있으니 한 줄 설명을 붙여 쓰라고 적었다

## 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 잉크 | `#17130E` | 글자, 어두운 바탕 |
| 동전 | `#FFC62B` | 심볼, 강조 |
| 종이 | `#FFF7E3` | 밝은 바탕, 어두운 바탕 위의 글자 |

뉴과의 짙은 남색·하늘색과 겹치지 않게 골랐다. 채널 전체의 색으로 쓸지는 아직 정하지 않았다.

## 파일

`svg/`가 원본이고 `png/`는 거기서 내보낸 것이다.

| 파일 | 내용 |
|---|---|
| `svg/wordmark.svg` | 워드마크. 밝은 바탕용. 배경 투명 |
| `svg/wordmark-on-dark.svg` | 워드마크. 어두운 바탕용 (글자가 종이색, 동전의 N 자리는 비어 있음). 배경 투명 |
| `svg/wordmark-on-gold.svg` | 워드마크. 금색 바탕용 (동전이 종이색) |
| `svg/lockup.svg`, `svg/lockup-on-dark.svg` | 한 줄 설명을 붙인 로고 |
| `svg/symbol.svg` | **채널 심볼 A (추천).** N으로 쪼개진 동전, 잉크 바탕 |
| `svg/symbol-coin-only.svg` | 동전만. 배경 투명 |
| `svg/symbol-alt-receipt.svg` | 채널 심볼 B. 영수증 위의 N |
| `svg/symbol-alt-letters.svg` | 채널 심볼 C. 글자 그대로 |
| `png/channel-icon-800.png` | **유튜브 프로필 사진용 (심볼 A, 800×800)** |
| `png/channel-icon-alt-receipt-800.png`, `png/channel-icon-alt-letters-800.png` | 심볼 B, C의 800×800 |
| `png/wordmark-2400.png` 등 | 워드마크와 한 줄 설명 로고. 폭 2400px, 배경 투명 |
| `png/preview.png` | 시안 전체를 모은 미리보기 |

## 세 심볼의 차이

| 시안 | 좋은 점 | 약한 점 |
|---|---|---|
| A. N으로 쪼개진 동전 | 워드마크 속 동전과 같은 모양. 24px에서도 N이 읽힌다 | 채널 이름이 글자로 보이지는 않는다 |
| B. 영수증 위의 N | 매 편 마지막의 영수증 한 장, 제목 기호 🧾와 이어진다 | 워드마크의 동전과 다른 그림이라 한 벌이 아니다. 24px에서는 영수증 모양이 뭉개진다 |
| C. 글자 그대로 | 이름이 바로 읽힌다 | 32px 아래에서는 글자가 뭉개진다 |

## 쓰는 법

- 밝은 바탕에는 `wordmark.svg`, 어두운 바탕에는 `wordmark-on-dark.svg`, 금색 바탕에는 `wordmark-on-gold.svg`를 쓴다. 금색 바탕에 기본 워드마크를 올리면 동전이 묻힌다
- 처음 보는 사람에게 닿는 자리(채널 배너, 영상 첫 화면)에는 한 줄 설명을 붙인 로고를 쓴다
- 글자의 비율과 동전 안의 N은 바꾸지 않는다. 늘이거나 기울이지 않는다

## 유튜브 프로필 사진 올리기

1. 유튜브 스튜디오 → 맞춤설정 → 프로필 → 사진에서 `png/channel-icon-800.png`를 올린다
2. 유튜브는 프로필 사진을 원형으로 잘라 보여 준다. 심볼은 원 안에 다 들어가게 그려 두었다

여러 안내 글에 따르면 권장 크기는 800×800px, 용량은 4MB 이하이고 JPG·GIF·BMP·PNG를 받는다(움직이는 GIF 제외). 2MB라고 적은 글도 있다. 이 파일은 약 37KB다. 유튜브 공식 안내는 직접 확인하지 못했으니 올리는 화면의 안내를 따른다.

## 다시 만들기

```
python3 scripts/enppang_logo.py library/brand/enppang/svg <NotoSansKR-Bold.ttf 경로>
node scripts/enppang_logo_png.js library/brand/enppang
```

- 글자와 심볼의 모양, 색, 비율은 `scripts/enppang_logo.py`의 숫자로 정해져 있다
- 한 줄 설명의 글꼴은 Noto Sans KR Bold다 (SIL Open Font License). 글꼴 파일은 저장소에 넣지 않았다. 윤곽선으로 바꿔 넣었으므로 SVG를 여는 데는 글꼴이 필요 없다
- PNG 내보내기에는 Playwright(Chromium)가 필요하다

## 확인하지 못한 것

- **비슷한 로고가 이미 있는지 찾아보지 않았다.** 원 안의 N은 흔한 모양이다
- **상표.** 기획서에 따르면 "N빵"은 36류·38류에 케이뱅크 등록이 있고, 41류 등록 여부와 변리사 확인이 남아 있다. 심볼에 알파벳 N을 썼으니 그때 로고도 함께 보여 준다
- 채널 배너와 영상 워터마크는 아직 만들지 않았다
